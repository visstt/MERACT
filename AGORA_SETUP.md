# Настройка Agora для стриминга

## Установка зависимостей

```bash
npm install agora-rtc-sdk-ng
```

## Переменные окружения

Добавьте в ваш `.env` файл:

```env
VITE_AGORA_APP_ID=your-agora-app-id
```

## Получение App ID от Agora

1. Зарегистрируйтесь на https://console.agora.io/
2. Создайте новый проект
3. Скопируйте App ID
4. Добавьте его в переменные окружения

## Структура компонентов

- `StartStream.jsx` - страница для запуска стрима
- `ActCard.jsx` - карточка стрима для просмотра
- `useAgora.js` - хук для работы с Agora SDK
- `streamApi.js` - API для работы со стримами

## Использование

1. **Запуск стрима:**
   - Перейдите на `/start-stream`
   - Заполните форму (название, категория, фото)
   - Нажмите "Начать стрим"
   - Система автоматически подключится к Agora

2. **Просмотр стримов:**
   - Активные стримы отображаются на странице `/acts`
   - Видео воспроизводится в ActCard компонентах
   - Автоматическое обновление списка каждые 30 секунд

## API эндпоинты

- `POST /stream/start` - начать стрим
- `GET /streams/active` - получить активные стримы
- `POST /stream/:id/stop` - остановить стрим

## Troubleshooting

1. Убедитесь, что Agora App ID правильно настроен
2. Проверьте права доступа к камере и микрофону
3. Убедитесь, что сервер возвращает правильные токены Agora
